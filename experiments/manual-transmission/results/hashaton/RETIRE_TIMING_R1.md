# Hashaton timing fixture R1 — RETIRED

Status: **RETIRED BEFORE QUALIFICATION**

R1's GitHub run #2 was green, but a subsequent pre-qualification integrity audit found that the Lion's Eye Diamond fixture modeled a single creature payload. LED actually discards the controller's entire hand as an activation cost. Multiple creature cards therefore create multiple simultaneous Hashaton triggers.

Consequences:
- a single Tishana's Tidebinder can counter one trigger and blank Hashaton, but it cannot erase sibling triggers already on the stack;
- ordinary source removal likewise cannot erase those triggers;
- LED's mana resolves before the triggers are put on the stack and can fund a Hashaton payment;
- the Hashaton controller chooses the relative order of simultaneous triggers.

R1 run/artifact is preserved for provenance but is not accepted as Phase-B completion evidence.

Superseding protocol: `MT_HASHATON_TIMING_FIXTURES_R2_2026_09_23`.

No qualification seeds were generated and no qualification outcomes were exposed before this retirement.
