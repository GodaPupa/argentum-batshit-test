# Protection attachment provenance

This source replaces the color-wide Aura exemption with per-grant protection
records. Innate, floating, and static grants remain independent even when they
have the same source or color. Explicit source retention applies only to that
grant; existing Ward definitions opt in. Targeting, damage, and blocking still
use the unchanged protection keywords.

Benevolent Blessing is not registered. Its remaining boundary is durable
activation-time capture of eligible attachment object identities for a
specific grant/host visit. Projection is currently pure and repeatedly rebuilt;
capturing the present attachment set in projection or at the next SBA would
retroactively exempt later attachments. Stamping only Aura attachment time
would miss effects beginning later after an ability/color/control change.
The eight focused cases qualify per-instance legality, not that snapshot
lifecycle. No gameplay admission; official counters unchanged.
