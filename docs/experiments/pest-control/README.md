# Project Pest Control experiments

This directory is reserved exclusively for Project Pest Control experiment protocols.

Goldfish Sample #1 is authorized as a 30-game development/engine baseline using the permanent Pest
Control v1.0 control and the validated Phase 3 solitaire policy. Its seed vector is frozen in
`goldfish-sample-1-seed-freeze.md` before execution. This authorization does not extend to challenger
construction, opponent self-play, Sample #2, or optimization. The permanent Pest Control v1.0
control in `docs/lab/PEST_CONTROL_STATUS.md` must not be silently changed.
