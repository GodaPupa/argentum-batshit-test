# Project Pest Control experiments

This directory is reserved exclusively for Project Pest Control experiment protocols.

Goldfish Sample #1 was authorized as a 30-game development/engine baseline candidate using the
permanent Pest Control v1.0 control and the validated Phase 3 solitaire policy. Its seed vector was
frozen in `goldfish-sample-1-seed-freeze.md` before execution. The exact vector was executed once,
but the sample was rejected by audit and is not a baseline. The complete rejected report and raw
telemetry are retained for investigation. This authorization does not extend to challenger
construction, opponent self-play, Sample #2, optimization, or rerunning Sample #1. The permanent
Pest Control v1.0 control in `docs/lab/PEST_CONTROL_STATUS.md` must not be silently changed.
